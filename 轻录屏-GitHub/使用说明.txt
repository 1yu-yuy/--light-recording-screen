轻录屏 — Windows 桌面悬浮球

使用：双击「轻录屏.exe」。无需安装 Python 或 Node。
请保留同目录的 ffmpeg.exe，它是录屏引擎。

• 按住悬浮球拖动；单击打开操作面板。
• 开始录屏 / 停止并保存：点击按钮，或按 Ctrl+Alt+R。
• 截屏：点击按钮，或按 Ctrl+Alt+S，自动保存 PNG。
• 点击「打开保存目录」查看文件。
• 退出：面板中点击「退出」，或右键悬浮球/托盘图标退出。
• 录制中退出会先停止并保存视频，请等待保存完成。

保存位置：程序同目录下的「录屏与截图」文件夹。
请先将压缩包解压到可写入的普通文件夹，再运行程序。
录屏格式：MP4，30 帧/秒，包含鼠标指针，声音编码为 AAC。
声音：点击悬浮球，在下拉框中选择，再开始录制。
  电脑声音（默认）：录下默认扬声器/耳机正在播放的声音。
  麦克风：录下默认麦克风输入。
  电脑声音 + 麦克风：同时录制并混合两路声音。
  静音：只录画面。
录制过程中不能切换声音模式，请先停止再修改。
使用麦克风需在 Windows 设置中允许桌面应用访问麦克风。
录制期间请勿切换或拔出默认声音设备。
电脑没有播放声音时录下的是静音，不会凭空产生声音。
声音先写入临时 WAV，停止时合并为 MP4；请等待保存完成。
若保存失败，保留的 .video.mp4 和 .wav 可用于恢复，详情见错误日志。
临时 WAV 单路最多约 4 GB，长时间录制请分段。
录制范围：开始时悬浮球所在的整块显示器；截图同理。
当前版本只支持整屏，不支持框选区域、暂停或开机启动。
Windows 10/11；依赖系统自带的 .NET Framework 4.5 或更新版本。
Windows 10 2004 及更新系统会请求从捕获画面中排除悬浮球，
不同系统/捕获方式可能表现不同；截图时程序会短暂隐藏。
受保护的视频、锁屏或安全桌面可能无法捕获。
快捷键被占用时会提示，仍可使用悬浮球按钮。

开发：修改 FloatRecorder.cs / AudioCapture.cs 后运行 build.ps1 编译。
FFmpeg 为第三方组件，来源为本机现有 ffmpeg.exe。
第三方组件许可及构建信息见 THIRD_PARTY.txt、ffmpeg-license.txt。
